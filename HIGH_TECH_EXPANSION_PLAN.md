## Implementation Notes

### Current Approach
1. Working through ranged weapons systematically by TL
2. TL5 being completed in batches (pistols → rifles → heavy weapons)
3. Each batch includes complete implementation across all methods

### Code Requirements
Each weapon must implement:
- `base_cost()` - Currency value
- `weight()` - Weight in pounds
- `tech_level()` - TechLevel
- `damage()` - WeaponDamage (dice + type)
- `accuracy()` - i32 accuracy bonus
- `required_skill()` - Skill enum

### Testing & Quality
- ✅ All code must pass `cargo check`
- ✅ All code must pass `cargo clippy`
- ✅ All code must pass `cargo test`
- ✅ Zero warnings policy

### Commit Strategy
- One batch per commit
- Descriptive commit messages following project style
- Format: `feat(items): Add [Category] - High-Tech Phase X Batch Y`
