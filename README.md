# Valinoreth

A Rust implementation of game mechanics from the GURPS (Generic Universal RolePlaying System) for personal use.

## About

This project recreates the character creation and game mechanics system as a programming exercise and personal tool. It includes implementations of:

- Character attributes and statistics
- Advantages, disadvantages, and skills
- Combat calculations
- Movement and encumbrance rules
- Dice rolling mechanics
